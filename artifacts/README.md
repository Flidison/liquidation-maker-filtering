# Research evidence

`results/` contains frozen **aggregate** outputs from the original research, plus exact specifications and policy
configurations. Original numeric fields are preserved; local filesystem paths are normalized.
`source_manifest.json` maps included files back to original relative paths and hashes.
`figures/` is regenerated by the six notebooks from these tables. No figure uses invented strategy results.

| Directory | Evidence |
|---|---|
| `quality` | Full-source audit summaries, integrity checks, exact histogram/quantile aggregates |
| `bursts` | Calibration thresholds, class counts, market association and window/offset sensitivity |
| `followthrough` | Episode-class aggregate returns, volatility and coverage/reconciliation checks |
| `statistics` | Day aggregates and adjusted follow-through statistical comparisons |
| `early_warning` | DC/Markov/W–L classifier metrics, ablations, calibration and split definitions |
| `evt` | Logistic/LightGBM comparisons, reduced 5s experiment and historical split diagnostics |
| `maker` | E0–E7 reports, daily sufficient statistics, parameter/feature/policy configs and robustness |
| `catboost/v1` | E9 comparisons, MSE, daily sufficient statistics, paired intervals and fixed parameters |

Exact configs remain beside results because the preserved pipeline reads them from its output directory.
`configs/publication.json` defines publication scope; it is not an alternative experiment specification.

No real Parquet observations, event-level exports, predictions, group caches, fitted `.joblib`/`.cbm` weights,
raw audit pickles, third-party slides or previous HTML/PDF exports are included. Some historical specifications
contain hashes/names for these omitted objects; those references document provenance, not file availability.
Historical completion markers must not be taken as proof that a fresh clone has performed the original calculation.

To refit, initialize a fresh reproduction workspace rather than training over these frozen tables.
See [reproducibility](../docs/reproducibility.md). Restored weights are ignored by Git and require upstream permission;
only load trusted serialized model objects.
